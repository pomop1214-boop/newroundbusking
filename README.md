# N.ROUND 버스킹 선곡 신청 페이지

곡 5개 이상을 입력하면, 유튜브 조회수를 기반으로 대중성을 상/중/하로 자동 분석해주는 페이지예요.
**완전 무료** 방식이에요 — 카드 등록이나 결제 없이 사용할 수 있어요.

## 어떻게 판단하나요?

곡 제목 + 가수로 유튜브에서 영상을 검색해서, 그 영상의 조회수를 기준으로 나눠요.

- 상: 조회수 3,000만 회 이상
- 중: 조회수 300만 회 ~ 3,000만 회
- 하: 조회수 300만 회 미만

(검색 결과가 실제 그 곡이 아닐 수도 있어서 100% 정확하지는 않지만, 크루 내부용으로 참고하기엔 충분해요.)

## 왜 서버가 필요한가요?

유튜브 API도 비밀 키가 있어야 호출할 수 있는데, 이 키를 index.html(브라우저)에 그대로 넣으면 누구나 볼 수 있어서 위험해요.
그래서 `api/analyze.js`라는 작은 서버 함수가 대신 유튜브에 물어보고, 결과만 브라우저로 돌려줘요.

## 배포 방법 (3단계)

### 1. 유튜브 API 키 발급받기 (무료, 카드 등록 X)

1. [console.cloud.google.com](https://console.cloud.google.com) 접속 → 구글 계정으로 로그인
2. 상단의 프로젝트 선택 → **새 프로젝트** 만들기 (이름 아무거나, 예: nround-busking)
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** 이동 → "YouTube Data API v3" 검색 → **사용 설정** 클릭
4. **API 및 서비스 → 사용자 인증 정보** 이동 → **+ 사용자 인증 정보 만들기 → API 키** 클릭
5. 생성된 키(긴 문자열) 복사해두기

> 결제 계정 연결 없이도 하루 10,000 유닛까지 무료로 쓸 수 있어요. 크루 사용량으로는 절대 넘칠 일이 없어요 (분석 1곡당 약 101유닛 사용 → 하루 약 99곡까지 무료).

### 2. GitHub에 올리기
새 저장소를 만들고 아래 3개 파일/폴더를 그대로 업로드하세요.
- `index.html`
- `api/analyze.js`
- `package.json`

### 3. Vercel에서 연결하기
1. [vercel.com](https://vercel.com) 로그인 → **Add New → Project**
2. 방금 만든 GitHub 저장소 선택 → **Import**
3. 배포하기 전에 **Environment Variables**에 아래를 추가하세요
   - Key: `YOUTUBE_API_KEY`
   - Value: (1단계에서 복사한 유튜브 API 키)
4. **Deploy** 클릭

배포가 끝나면 `xxx.vercel.app` 같은 주소가 생겨요. 이 주소를 크루원들에게 공유하면 끝!

## 참고
- 곡 제목만 입력하고 가수를 비워두면 검색 정확도가 떨어질 수 있어요. 가수명을 같이 적어주면 더 정확해요.
- 하루 무료 할당량(10,000 유닛)을 초과하면 그날은 분석이 잠깐 안 될 수 있어요 (자정 기준 리셋, 결제로 이어지지 않고 그냥 요청이 실패해요).
